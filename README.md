## 📌 Project Overview

### Task 01 – AI-Powered Invoice Extraction System

A Python-based invoice information extraction system designed to identify and extract structured data from unstructured invoice documents.

**Key Features:**
- Automated extraction of invoice details using Python.
- Structured data validation using Pydantic.
- Integration with the Ollama API for AI-powered verification.
- Validation of extracted fields against the original document.
- Structured JSON output for reliable data representation.

**Technologies Used:** Python, Ollama, Pydantic, Regular Expressions, JSON.

**Repository:** [View Task 01 – Invoice Extractor](https://github.com/shawnmcconnell0801/structured-llm-extractor)

---

### Task 02 – ShawnAI: AI-Powered Chatbot

ShawnAI is a locally powered AI chatbot application developed to provide an interactive conversational experience through a professional web interface.

**Key Features:**
- Interactive chatbot interface built with Streamlit.
- Local AI model integration using Ollama.
- Persistent conversation storage using SQLite.
- Conversation creation, management, and retrieval.
- Chat history management and conversation export.
- Professional and user-friendly application interface.

**Technologies Used:** Python, Streamlit, Ollama, SQLite.

**Repository:** [View Task 02 – ShawnAI](https://github.com/shawnmcconnell0801/shawnai-streamlit-ai-agent)
